# 自分のキャラ・背景を登録する

リファレンス画像を渡すと、**そのキャラで**描いてくれます。
無くても動きますが、シリーズものを続けるなら用意する価値があります。

## 立ち絵の置き方

決まったディレクトリ構造はありません。好きな場所に置いて `-r` で渡します。
運用例:

```
assets/
├── chars/
│   ├── hero.png            通年版
│   ├── hero_summer.png     夏服（半袖）
│   └── rival.png
├── bg/
│   └── classroom.png       背景の美術設定
└── props/
    └── redscarf.png        アイコニックな小物
```

```bash
./scripts/forge.sh -n my.omny.yaml -r assets/chars/hero.png -r assets/chars/rival.png
```

## リファレンスは最大3枚が目安

増やしすぎると1枚あたりの効きが薄れます。そのシーンに出る主要キャラだけに絞ってください。
**4人以上出る作品**では、リファレンスを渡すのは主役2〜3人にして、残りは OMNY の `materials.note` に文章で書くほうがうまくいきます。

## OMNY 側の書き方

`materials` に素材を宣言して、各コマの `assets` で参照します。

```yaml
materials:
  - key: "主人公"
    type: "character"
    keywords: ["hero", "立ち絵"]
    note: "黒髪ショート・赤いマフラー・制服。マフラーは必ず付けている"
  - key: "教室"
    type: "background"
    keywords: ["classroom", "背景"]
    note: "夕方の教室。西日が入る。机は木製"

pages:
  - page: 1
    panels:
      - id: 1
        assets: ["主人公", "教室"]
```

**`note` が効きます。** リファレンス画像があっても、
「この特徴は絶対に省略しない」という一文を書いておくと保たれやすくなります。
逆に**リファレンス画像が無い場合は `note` だけが手がかり**になるので、
見た目の要点（髪型・色・服・体型・雰囲気）を具体的に書いてください。

## 🚨 季節で衣装を切り替える

実際に踏んだ失敗です（`docs/pitfalls.md` 罠9）。

35℃の設定でかき氷と扇風機を描いた画面の中で、キャラだけ長袖の上着を着ていました。
原因は**通年版の立ち絵をリファレンスに使っていた**こと。

対策：
- **衣装差分を用意して、季節でリファレンスを切り替える**
- 夏は `hero_summer.png`、冬は `hero_winter.png` のように分ける
- 生成後に**季節の記号（かき氷・こたつ・雪）と服装が矛盾していないか必ず目で見る**

## 一度デザインしたものを資産化する

リファレンス画像が無いキャラ・背景は、作画AIがその場でデザインします。
気に入ったデザインが出たら、**その絵を保存してリネームし、次回のリファレンスにする**と世界が育ちます。

```
生成された絵を見る → 良ければ切り出す → 分かりやすい名前でリネーム → assets/ に置く
```

これを続けると、**同じ家・同じ制服・同じ小物**が作品をまたいで出てくるようになります。
シリーズものではこれが効きます。

## 背景素材の扱い

背景のリファレンスは「**そのシーンの美術設定資料**」として渡されます。
場所のデザイン・色彩・光・小物の配置を踏襲するためのもので、
**構図をそのまま複写してキャラを上に置く合成は禁止**されています（OMAY の style_notes）。

コマごとにカメラアングルは自由に変わります（寄り・引き・あおり・俯瞰・背後から）。
なので背景リファレンスは1枚あれば、いろんな角度で描き起こしてくれます。

賑わう場所の背景を作るときは**モブを入れてください**。無人の祭り会場はホラーになります。
