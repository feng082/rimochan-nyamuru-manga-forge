本提示词会把故事脚本结构化为遵循 **Nyamuru Data Model（NDM）v10.2** 的彩色漫画分镜，并以 **Open Manga Name YAML（OMNY）** 格式输出。

**Nyamuru Data Model（NDM）** 定义漫画分镜的结构、分格、人物、气泡和素材引用；别名为 **Nyamuru🐱**。

**Open Manga Name YAML（OMNY）** 是将 NDM 保存和交换为 YAML 的序列化格式。
**Open Manga Artwork YAML（OMAY）** 是用于把 OMNY 绘制成漫画的图像生成指令文件，汇集了作画、演出规则（style_notes）与版式规范（layout_spec）；参见 [standard.omay.yaml](../omay/standard.omay.yaml)。

收到新的脚本后，请按以下流程和模板输出 OMNY。
输出的 OMNY 必须包含每页的分格坐标（按 A4 基准）。面向图像生成 AI 的作画、演出规则与版式规范由 OMAY 承担，**不应写进 OMNY**。实际工作流中，OMAY 只需一次性设置到图像生成端的项目指令中；每部作品只交付 OMNY。
不要把 OMNY 全文作为聊天代码块粘贴，而应**提供可下载的 `.yaml` 文件**。不同 LLM 的交付方式请见 **§D**。

## 步骤

1. **阅读脚本，按页面和格子（panel）拆分。**

   若脚本明确标有“第几页”，则遵循它。未标明时，按内容段落拆页，并简要说明拆分理由。

2. **为每页设计分格。**

   - 画布以 A4（210 × 297 mm，竖版）为基准。
   - 🚨 **每页最多 6 格，必须遵守。** 超过 6 格会使台词绘制崩坏。可少至 1 格，不得多于 6 格。
   - 每格使用 `rect`（矩形）或 `polygon`（多边形／对角切分）定义。
   - `id` 从 1 开始，按右上 → 左下的日式右装订阅读顺序排列。
   - 按内容创造强弱：高潮用大格，快速场景用窄条小格，情绪停顿用接近方形的格子，强动作可用对角切分多边形。
   - 🚨 **相邻页面必须采用不同分格模式，这是最重要的规则。** 禁止全部页面使用同一骨架（例如“大上格 → 右格 → 左格 → 大下格”）。从 §B 为每个场景选择合适模式；犹豫时随机选不同模式以创造变化。
   - 高光场景（高潮、感动、转折、登场亮相）可不受模式集限制，自由分格。优先采用对角切分、占页面 2/3 的大格、竖长格、由密集小格接大格等漫画式演出。
   - 关键台词、决心宣言、气势台词和重要反应要用说话者的较大面部特写格，并在该格的 `action` 中明确写“面部特写”“胸部以上”等。
   - 🪝 **每页最后一格（左下）应设计为悬念。** 用疑问、气息、未完成动作或以“？”结尾的台词，让读者想翻页；再由下一页开头的较大格承接答案（翻页揭示）。多页脚本最好先确定悬念格再拆页。悬念格可较小，下一页承接格可较大（§B 的 J → L 是典型组合）。
   - **一个格子含 3 个以上气泡时，面积至少应有横向 190 mm 级别。** 台词多的格子必须更大，无台词格子可更小。文字与画面同步生成，面积不足会直接导致文字压缩。
   - 🚫 **禁止“田字格”。** 2 × 2 布局中，上下两排的竖向分割线若对齐，会使“右→左”与“先读右列再读左列”的顺序不清。需要 2 × 2 时，必须错开每排的竖线位置。
   - ✂️ **出血格只允许用于高光场景。** 左右可延展到 `x=0` / `x=210`，底边可延展到 `y=297`；**顶部因页眉带只能到 `y=10`**。适用于角色登场、亮相、跨页大画面等需要最大空间感的格子。每页最多 1～2 格，过度使用会失效。参见 §B 的模式 M～Q。
   - 普通格子的外圈留约 2～3 mm 白边，格框约 1 mm 黑线。出血边没有白边也不画边线。
   - 分格参考请见 **§B 分格模式集**。

3. **为每格指定人物布局（figures）与气泡布局（bbox/anchor）。**

   - 在 `figures` 列出该格会出现的角色；每人指定 `bbox`（画布绝对坐标 mm）、`anchor`（相对位置词）与 `size`（full / waist-up / bust-up / face）。只在格外说话的角色不得放进 figures。
   - 为每个气泡指定 `bbox` 与 `anchor`；anchor 和数组顺序（右上 → 左下）应一致。
   - 📐 **气泡 bbox 的纵横比必须匹配文字排版方向。** 竖排气泡应为**竖长**边界框（常规参考为 w40 × h50 mm）；横排气泡应为**横长**边界框（常规参考为 w50 × h40 mm）。可按文字量和格子大小缩放，但不得颠倒长宽方向。
   - 🚨 **气泡 bbox 禁止与任何 figure 的脸部区域（其 bbox 的上方 1/3）相交；可与躯干重叠。** 输出 OMNY 后，应对所有气泡和人物组合自检 x、y 范围是否相交，并报告结果；同时自检**人物居中原则**（人物中心偏差 ±5%、页面面积重心）并报告。
   - bbox 应位于格内（polygon 格需避开斜边）。发言顺序、anchor 和 bbox 三者应指向同一布局。
   - 🧍 **人物居中原则（常规对话格的默认布局）**：
     - 没有动作演出（对决、亮相、双人并列、出血高光格等）的对话格中，将人物放大置于格子的中心区域。
     - 人物 bbox 高度以格高约 90% 为参考，使用 bust-up / waist-up 让人物主导格子，禁止缩在角落。
     - 人物 bbox 中心应位于格子水平中心 ±5% 内。
     - 气泡按阅读顺序**分布在人物右侧 → 左侧**。参考：2 个气泡=右 1 左 1；3 个=右 1 左 2 或右 2 左 1；4 个=右 2 左 2。`bubbles` 数组顺序必须保持右 → 左。
     - 只有 1 个气泡时可放在任一侧，但要在同一页中分散，避免都偏右；人物可向气泡反侧移动半步（约格宽 20%）。
     - 避免气泡和脸部区域相交时，**不移动人物，移动气泡。** 反复把人物向右推会导致整页重心右偏。
     - 仅当演出明确需要时可例外：对峙的左右布局、双人对称、对角楔形格、需要留出背景的展示格等。例外原因必须写进 `action`。

4. **每格必须指定背景细节等级 `bg`（-1 / 0 / 1 / 2）。**

   - 🚨 **不得因为演出判断而自动选择 bg:-1。** 只有用户明确要求某格（或整部作品）无背景时才可用；未明确时从 0 / 1 / 2 选择。
   - **bg:-1：不绘制背景。** 用于后续键控或人工替换背景。
   - **bg:0：没有具体物体，只用情绪色和效果。** 不画风景或室内，在匹配场景情绪的背景色（平涂或渐变）上叠加集中线、漫符、网点、光环、闪光、爱心等。**禁止纯白背景**。示例：愤怒=红色，喜悦=暖色，惊讶=黄色，紧张=紫至藏蓝，感动=金至桃，宁静=蓝色。适用于面部特写、情绪爆发、关键台词、反应和动作瞬间。
   - **bg:1：简易背景。** 在**符合场景的背景色渐变**上，仅加入 1～2 个地点符号（墙线、窗框、桌沿、沙发靠背、前景小物剪影等）。**避免白底**。也可使用前景物体 + 远处色彩渐变形成纵深。它是常规对话格和安静场景的默认，虽不细画也必须用颜色营造空气感。
   - **bg:2：详细背景。** 充分刻画地点的展示格。**每页最多 2 格**，用于开场、场景转换、风景展示或大画面。由分镜设计者自由决定何处需要展示，首格不必固定为 2。
   - 建议配比：对话交锋=1，情绪／关键台词／笑点=0，展示格=2；位置可自由。**同页混有 0、1、2 是理想状态。** 禁止所有格子均为 2，以免信息过量、削弱视线引导。
   - `bg:0` 与“面部特写”“emphasis”相性很好，关键格通常设为 `bg:0`。
   - bg:0/1 的颜色意图最好写进 `action`，例如“背景为紧张的紫色渐变”；未写时由作画 AI 从场景判断。
   - **背景色默认低至中饱和**。情绪色平涂／渐变只用于传达氛围，不能压过角色和台词。高饱和鲜艳背景仅限情绪爆发、关键格最大强调等明确意图，不能无故使用原色平涂。
   - **🎬 拿不准时，可借鉴影视演出：**
     - 背景色可先设计“色彩戏剧曲线／色彩脚本”：将整页或全作的情绪波动先写成色彩变化序列，例如日常浅蓝 → 异样黄色 → 紧张紫蓝 → 静谧深蓝 → 欢喜金色 → 余韵橙色。各格从曲线中取色即可；相邻格色相差越大，场景或情绪转变越强（缓变=时间经过，突变=事件）。
     - 将 bg 深度理解为“镜头景别”：bg2=远景建立镜头，bg1=中景对话距离，bg0=近景贴近情绪。可用 bg 2 → 1 → 0 重现电影从远到近的节奏。
     - 将漫符和效果理解为“光线与镜头”：逆光剪影=严肃或决心；顶光=神圣或重逢；下方打光=不安或恐惧；镜头耀光／散景=感动或回忆；前景虚化=沉浸感。将这些影视表达转化为漫符和渐变，可提升格子的说服力。

5. **创建素材清单（materials），并写明格子对应关系。**

   - 在顶层 `materials` 列出本作绘制所需的**人物、背景和小物素材**。
   - 每种素材都需有 `keywords`（搜索关键词数组），让作画代理能按文件名搜集素材。例如 key“角色 A 的日常服”可用 keywords `["角色A", "日常服", "便服", "立绘"]`；key“厨房背景”可用 `["厨房", "背景"]`。
   - `note` 写外观要点，也兼作**找不到素材时的设计指针**，例如“银色长发、围裙、雀斑”。
   - 在每格的 `assets` 数组中写入该格所用素材的 `key`，例如 `assets: ["角色A的日常服", "厨房背景"]`。不需要素材的格子（如 bg:0 情绪格）可省略。
   - 作画代理应在**开始工作前**按 materials 的 keywords 搜索并收集本地素材，按各格 assets 作为参考。**若找不到相应素材，不得等待，应按 note 和作品画风自由设计，并在后续格子保持一致。**
   - 本提示词只负责**枚举所需素材（materials）与在分镜中指定素材（assets）**。素材收集、重新生成、验收、命名和目录整理等素材管理规则由制作流水线（如 manga-pipeline 技能）负责。

6. **所有台词必须写入 `bubbles` 数组。** 禁止把台词写成格子下的独立字段。

   - 一个格子可有多个气泡。连续同一说话者的台词按语义段落放入一个格子。
   - **每个气泡的说话者用 `speaker` 表示。** 与同格前一气泡为同一说话者时可省略；旁白（caption）、拟声词（handwritten）等无说话者气泡也省略。借此可表示多说话者的对话。
   - **格内发言顺序直接决定人物站位。** 作画时第一个说话者在格子右侧，后续按发言顺序向左排列（见 OMAY style_notes）。若想改变站位，可重排发言顺序或在 `action` 中明确构图。
   - 上述站位规则只是**省略 figures 时的回退规则**。明确给出 figures（bbox/anchor）的格子始终以它们为准，不得借此规则把人物推向右侧。
   - **长台词必须拆分为能自然放进一个气泡的长度。** 在句号、逗号或语义断点拆成同一 `bubbles` 数组的多个 `text`；同一说话者在第二个起可省略 `speaker`。每个气泡建议约 20～40 个汉字，竖排可放 2～3 列。单条 text 过长会令气泡过大、画面失衡或文字不可读。

7. **每个气泡都用 `shape` 指定形状。**

   - 气泡形状不是固定分配的，应由分镜设计者根据台词情绪和类型逐次选择。
   - 可用的 9 种词汇如下：

     | shape | 形状 | 适用场景 |
     |---|---|---|
     | `normal` | 圆形常规气泡 | 普通对话（**省略时默认**） |
     | `thought` | 云朵形 | 内心、想象、梦境 |
     | `square` | 方形边框 | 内心独白、回忆旁白、冷静内语 |
     | `caption` | 框外说明框 | 旁白、时间经过、地点说明（格子角落） |
     | `flash` | 锯齿形 | 喊叫、强烈惊讶、电话或机械音 |
     | `uniflash` | 海胆闪光：无数针状线放射的尖刺气泡 | 最大级别尖叫、极强冲击、反转时的“什么……！？”、**内心尖叫吐槽**（可配合 monologue） |
     | `wobbly` | 颤抖波浪线 | 虚弱、恐惧、低声、无力 |
     | `whisper` | 虚线 | 悄声、秘密谈话 |
     | `handwritten` | 无气泡手写字 | 拟声词、小声嘀咕、摇晃文字 |

   - 无法判断时：喊叫用 `flash`；**该页最大的尖叫或冲击用 `uniflash`**（每页建议最多一个，过多会失效）；内心用 `thought` 或 `square`（感性角色用云朵，理性角色用方框）；发抖和细弱声音用 `wobbly`；叙述文字用 `caption`。
   - **搞笑漫画中无声的内心尖叫吐槽可组合 `monologue: true` 与 `shape: "uniflash"`**，例如“你是认真的吗！？”；声音没有说出口，但可用海胆闪光炸裂。这是允许的惯用演出，仍需遵守每页最多一个的建议。

8. **内心独白（原稿带圆括号的台词）必须加 `monologue: true`，并从 `text` 中移除圆括号“（）”。**

   - `monologue` 是**气泡级别**的标记。同一格可共存说出口的台词和内心独白，只对内心独白气泡使用。
   - `monologue` 表示其语义，**视觉形状由 `shape` 决定**。除 `thought`、`square` 外，惊愕的内心吐槽也可自由使用 `uniflash` 或 `flash`。
   - 若在 `text` 中保留括号，生成图会将“（）”本身画进气泡。读取原稿后把括号视作内心标记并丢弃：原稿“（……！？）”应变成 `text: "……！？"` + `monologue: true` + `shape: "thought"`。

9. **表情和动作写入 `action`，与台词分离。**

   演出指令（如“放大气泡中的某个词”）不得写入 `action`，应写在对应气泡的 `emphasis`。

10. **整部作品中的角色名必须统一。**

    发现名称写法不一致时应统一，并报告这一修改。

11. **必须保留固定字段，且不得把通用作画规则写入 OMNY。**

    `meta` 的右装订、竖排、黑体格式字段与 `page_count` 都必须保持固定值并彼此一致。`meta.style_notes` 只放**本作专属的作画指令**；无专属指令时保持空数组。仅当作品信息指定了**画风**时，才在数组首项加入：

    `"画风：<指定画风>。角色设计、线条笔触、变形程度、眼睛和头发的画法、效果网点都必须在全篇统一为此画风"`

12. **注意 OMNY 所基于 YAML 的陷阱。**

    在同一映射中重复写同一个 key，YAML 会用后面的值静默覆盖前面的值。台词统一使用 `bubbles` 数组而不是格子下的独立字段，正是为了避免此问题。

14. 输出后应附上**所使用图像素材清单**（materials 与各格的对应关系），然后用简短说明记录改动和判断（拆格方式、分格意图、bg 配比意图、名称统一等）。

bg 定义、边距等数值会同时出现在本提示词的“步骤”与 OMAY 中；这是因为二者读者不同而刻意重复。修改规则时，必须同时同步两处。

## §A Nyamuru Data Model（NDM）v10.2 Schema 定义（OMNY 表达）

```yaml
manga:
  schema_name: "Nyamuru Data Model"   # NDM 的正式固定标识，不含表情符号
  schema_version: 10.2                # NDM 版本
  meta:
    title:                # 作品标题
    author:               # 作者名（可选；存在时绘制在每页下方中央）
    format:               # 例如：彩色漫画
    page_count:           # 总页数（整数），必须与 pages 数组元素数一致
    reading_direction:    # "right-to-left"（右装订，固定）
    text_orientation:     # "vertical"（竖排，固定）
    font:                 # "黑体"（固定）
    style_notes:          # 仅限本作专属作画指令的数组，例如画风；无则空数组，不写 OMAY 的通用规则

  setting:
    location:             # 地点
    time:                 # 时段
    weather:              # 天气
    background:           # 背景元素（数组）
    props:                # 小物（数组）
    situation:            # 场景说明

  characters:             # 登场人物（数组）
    - name:               # 名称
      role:               # 角色定位与属性

  materials:              # 素材清单（供作画代理搜集）
    - key:                # 从各格 assets 引用的素材名，例如“角色A的日常服”
      type:               # "character" / "background" / "prop"
      keywords:           # 按文件名搜索的线索数组，例如 ["角色A", "日常服", "立绘"]
      note:               # 外观要点；找不到素材时的设计指针（可选）

  pages:                  # 页面（数组）
    - page:               # 页码（整数）
      canvas:             # 本页画布，原则上 w:210, h:297, unit:mm
        w: 210
        h: 297
        unit: mm
      panels:             # 格子（数组；数组顺序即阅读顺序）
        - id:             # 格子编号，从 1 开始，右上 → 左下
          shape:          # 格子形状
            type:         # "rect" 或 "polygon"
            # rect：x, y, w, h（x、y 是左上坐标，单位 mm）
            # polygon：points [[x1,y1],[x2,y2],...]（顶点坐标，单位 mm）
          bg:             # 必填背景细节等级 -1/0/1/2；-1=无背景（仅明确要求时），0=情绪色+效果，1=简易背景，2=详细背景（每页最多 2 格）
          figures:        # 格内人物布局（数组，可选；省略时按发言顺序规则自由构图）
            - name:       # 角色名，需与 characters 一致
              bbox:       # {x, y, w, h}，画布绝对坐标（mm），绘制区域参考
              anchor:     # right/left/center/top-right/top-left/bottom-right/bottom-left（必须遵守）
              size:       # full/waist-up/bust-up/face（优先于 bbox 尺寸）
          assets:         # 本格所用素材，materials key 的数组，可选
          bubbles:        # 气泡数组；竖排时从右上气泡开始排列
            - text:       # 气泡正文（必填）
              speaker:    # 说话者（可选；省略=同格前一气泡的说话者；旁白和拟声词也省略）
              shape:      # 可选形状：normal/thought/square/caption/flash/uniflash/wobbly/whisper/handwritten；省略=normal
              emphasis:   # 气泡中要放大的词（可选）
              monologue:  # 内心独白时为 true（可选；视觉形状由 shape 决定）
              bbox:       # {x, y, w, h}，气泡主体参考（mm），不含尾巴
              anchor:     # 格内相对位置；必须遵守，只表示位置；阅读顺序以 bubbles 数组为准
          action:         # 表情和动作说明；没有时为 null
```

### 字段规则

- `meta.page_count` 为整数；`pages` 是实际页面数组。完成后，page_count 必须等于 pages 元素数。
- `meta.author` 可选。有用户提供的作者名才填写，禁止编造。填写后会成为每页底部中央页脚（坐标见 OMAY `layout_spec`，绘制方式见 OMAY `style_notes`）。
- `meta.reading_direction` / `text_orientation` / `font` 是固定值：`"right-to-left"` / `"vertical"` / `"黑体"`。
- `meta.style_notes` **只放本作专属作画指令**，例如画风；无则空数组。适用于所有格子的通用作画、演出规则和 `layout_spec` 由图像生成指令文件 **OMAY（Open Manga Artwork YAML）** 提供，不能输出到 OMNY。
- `materials` 是**本作使用素材的目录**。`key` 应为易读中文名，`keywords` 用于按文件名搜索。作画代理开工前按此搜集素材；找不到时按 `note` 自由设计。
- `pages.canvas` 基于 A4，原则上所有页面一致：`w:210, h:297, unit:mm`。
- `pages.panels` 数组顺序即阅读顺序，必须与 `id` 一致。
- `pages.panels` 每页**最多 6 格**，禁止 7 格以上，否则台词绘制会崩坏。
- `panels.shape.type` 只能是 `"rect"` 或 `"polygon"`。
- `panels.bg` 必须为 **-1/0/1/2 整数，所有格必填**。-1=无背景（只在明确要求时，不能自行选用），0=无具体背景（仅情绪色平涂／渐变与效果），1=简易背景（场景色加 1～2 个符号元素），2=详细背景（**每页最多 2 格**，位置不限）。bg:-1 不占用每页 2 格 bg:2 的限额。
- `panels.assets` 可选，列出该格应参考的素材 `key`。如 bg:0 情绪格不需要素材，可以省略。
- `bubbles` **必须始终是数组**，即便只有 1 个气泡。每项 `text` 必填；长台词拆分遵循步骤 6。
- `bubbles[].speaker` 可选。省略时表示**与同格前一气泡相同的说话者**；caption 旁白、handwritten 拟声词等无说话者气泡也省略。
- `bubbles[].shape` 可选，须从 9 个值中选择：normal/thought/square/caption/flash/uniflash/wobbly/whisper/handwritten；省略为 `normal`（圆形常规气泡）。`uniflash` 每页建议最多 1 个。
- `bubbles[].emphasis` 可选，只指定需要放大的词。
- `bubbles[].monologue: true` 仅用于内心独白气泡。原稿中带“（）”的台词属于此类，但 `text` 中必须删除括号（见步骤 8）；**视觉边框仍由 `shape` 决定**，并不固定为方形。
- `action` 只写表情和动作；没有时使用 `null`。

## §B 分格模式集（参考）

以下是常见版式示例。可按脚本内容选择、组合和修改；坐标单位为 mm，以 A4（210 × 297）为基准。
**每一页必须使用不同模式。** 犹豫时随机选择不同模式来制造变化。高光场景可以不受模式限制，自由切分。

### 选择参考

| 模式 | 适用场景 |
|---|---|
| A：3 格纵向堆叠 | 安静对话、旁白为主、风景变化 |
| B：少年漫画 6 格 | 标准推进、动作与对话混合 |
| C：单页大画面 | 最大高光（用一张画呈现一页） |
| D：四格均分 | 节奏快的对话、均匀的时间推进 |
| E：对角动作 | 动作、惊讶、事件发生 |
| F：蓄势 → 大格 | 感动、告白、重逢（蓄势后以大格释放） |
| G：图解宽幅 | 讲解、说明场景（分开图与说话者） |
| H：对话接力 6 格 | 密集逗哏、连续铺垫 → 笑点 |
| I：竖长亮相 | 角色登场、变身、定格姿势 |
| J：渐进悬念 3 段 | 日常 → 异样，并在页末留悬念（下页用 L 承接） |
| K：纵向 3 列蒙太奇 | 时间流逝、并行推进、“与此同时……”、工作过程 |
| L：翻页承接大格 | 解开上一页悬念、释放登场（承接 J） |
| M：出血单页大画面 | 最大高光（比 C 更强调延伸至纸边） |

| O：出血翻页承接 | 用左右出血大格承接上一页悬念（L 的出血版） |
| P：出血悬念 3 段 | 用出血强化页末悬念（J 的出血版） |

| U：对角翻页承接 | 冲击承接、急转直下（斜底大格制造势头） |

```yaml
  - {id: 2, shape: {type: polygon, points: [[200,75],[200,230],[85,230],[125,75]]}}  # 右侧，对决者 A，斜向竖切
  - {id: 3, shape: {type: polygon, points: [[120,75],[80,230],[10,230],[10,75]]}}    # 左侧，对决者 B，斜向竖切
  - {id: 4, shape: {type: rect, x: 10, y: 235, w: 190, h: 52}}                       # 交锋／下一页铺垫横条
```

### 模式 T：楔形连击（恐慌、混乱、连续交锋）

将中段做成 3 个上下宽度交替的楔形格，摇动视线并持续推进。适用于混乱、斗嘴、同时发生的多件事。

```yaml
canvas: {w: 210, h: 297, unit: mm}
panels:
  - {id: 1, shape: {type: rect, x: 10, y: 10, w: 190, h: 55}}                          # 起因横条
  - {id: 2, shape: {type: polygon, points: [[200,70],[200,210],[152,210],[120,70]]}}   # 右楔形，下窄
  - {id: 3, shape: {type: polygon, points: [[115,70],[147,210],[57,210],[85,70]]}}     # 中楔形，下宽
  - {id: 4, shape: {type: polygon, points: [[80,70],[52,210],[10,210],[10,70]]}}       # 左楔形，下窄
  - {id: 5, shape: {type: rect, x: 10, y: 215, w: 190, h: 72}}                         # 结果宽格
```

### 模式 U：对角翻页承接（冲击承接、急转直下）

L 的变体。将开头大格的底边切成斜线以增加势头，下方两格也用斜槽承接。适合强烈地承接上一页悬念。

```yaml
canvas: {w: 210, h: 297, unit: mm}
panels:
  - {id: 1, shape: {type: polygon, points: [[10,10],[200,10],[200,200],[10,170]]}}     # 开头占 2/3 的大格，斜底，可用 bg:2
  - {id: 2, shape: {type: polygon, points: [[200,205],[200,287],[103,287],[113,192]]}} # 右下，周围反应
  - {id: 3, shape: {type: polygon, points: [[108,192],[98,287],[10,287],[10,175]]}}    # 左下，承接／下一页铺垫
```

## §C OMNY 模板（骨架）

`meta.style_notes` 仅包含本作专属作画指令（例如画风）；没有时用空数组。
通用作画、演出规则和版式规范在 OMAY 中，不能写入 OMNY。

```yaml
manga:
  schema_name: "Nyamuru Data Model"   # NDM 的正式固定标识，不含表情符号
  schema_version: 10.2                # NDM 版本
  meta:
    title: ""
    author: ""      # 作者名，可选；指定后绘制在每页底部中央
    format: "彩色漫画"
    page_count: 0   # 完成后应等于 pages 数组的实际元素数
    reading_direction: "right-to-left"
    text_orientation: "vertical"
    font: "黑体"
    style_notes: [] # 仅限本作专属作画指令，例如指定画风时的一行；没有则保持空数组

  setting:
    location: ""
    time: ""
    weather: ""
    background:
      - ""
    props:
      - ""
    situation: ""

  characters:
    - name: ""
      role: ""

  materials:
    # 列出本作所需素材；作画代理会在开始前用 keywords 搜索和收集
    - key: "角色A的日常服"
      type: "character"
      keywords: ["角色A", "日常服", "便服", "立绘"]
      note: "银色长发、雀斑、围裙；如果没有素材，按此 note 自由设计"
    - key: "厨房背景"
      type: "background"
      keywords: ["厨房", "背景"]
      note: "明亮的厨房，有木纹吊柜和窗户"

  pages:
    - page: 1
      canvas: {w: 210, h: 297, unit: mm}
      panels:
        # 展示格 = bg:2（位置自由；每页最多 2 格。此例只是恰好位于开头）。assets 写明本格对应素材
        - id: 1
          shape: {type: rect, x: 10, y: 10, w: 190, h: 80}
          bg: 2
          figures:
            - name: "角色A"
              bbox: {x: 20, y: 15, w: 55, h: 70}
              anchor: "left"
              size: "full"
          assets: ["角色A的日常服", "厨房背景"]
          bubbles:
            - text: ""
              shape: "caption"   # 引入旁白为框外说明框；无说话者时省略 speaker
              bbox: {x: 130, y: 15, w: 65, h: 25}
              anchor: "top-right"
          action: null

        # 对话格 = bg:1（简易背景）。示例包括多个气泡、强调词、形状指定和 figures/bubbles.bbox
        - id: 2
          shape: {type: polygon, points: [[200,95],[200,170],[105,170],[115,95]]}
          bg: 1
          figures:
            - name: "角色A"
              bbox: {x: 155, y: 105, w: 40, h: 60}
              anchor: "right"
              size: "waist-up"
          assets: ["角色A的日常服"]
          bubbles:
            - text: "第一句台词"                           # 省略 shape = normal（圆形）
              speaker: "角色A"
              bbox: {x: 125, y: 100, w: 25, h: 25}         # 避开 figure 的脸部区域（y:105-125，x:155-195）
              anchor: "top-right"
            - text: "第二句台词，把这里的真心话放大"
              shape: "flash"                              # 喊叫使用锯齿形
              emphasis: "真心话"
              bbox: {x: 115, y: 130, w: 35, h: 30}
              anchor: "bottom-left"
          action: "若无其事的表情"

        # 情绪格 = bg:0（无具体背景，只有效果）。省略 figures = 回退示例：按发言顺序自由构图。内心独白的 text 不写圆括号，形状由 shape 选择
        - id: 3
          shape: {type: polygon, points: [[115,95],[105,170],[10,170],[10,95]]}
          bg: 0
          bubbles:
            - text: "……！？"
              speaker: "角色A"
              shape: "thought"   # 感性的内心独白用云朵形；理性的独白可用 square
              monologue: true    # 内心独白按气泡指定
          action: "面无表情，背景却变成宇宙的搞笑格"
```
