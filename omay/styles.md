# 画風パレット（styles）

OMNY の `meta.style_notes` の**先頭1行**に貼るだけで画風を差し替えられる呪文集です。

```yaml
style_notes:
  - "画風: <下の各項目の括弧の中身>。キャラクターデザイン・線のタッチ・デフォルメ度・目や髪の描き方・効果トーンをこの画風に合わせて全編で統一する"
```

**使い方**：ネームのOMNYはそのまま、この画風1行だけ差し替えて再発注します。
コマ割り・セリフ・figures・bbox は一字も変えません。同じネームで別の画風に刷り直せます。

## コツ

- 「地続きの画風」（水彩絵本など）は変化が小さい。**大きく変えたいときは「画材＋支持体（紙）」を指定する** — クレヨン＋画用紙、墨＋和紙、色画用紙を切って貼る、など
- 依頼文にも「アニメ塗り・デジタルのなめらかな塗りは禁止」「中途半端にきれいにしない」と念押しすると振り切ってくれる
- ピクセルアート等の「質感自体がキャラの一部」であるキャラは、どの画風でもその質感を維持する（水墨画では唯一の色になって決まる）
- ⚠️ **同一セッションで連続発注すると直前の画材を引きずる**（油彩→ちぎり絵が厚塗りのままになった）。次の画風では「さっきの画材は一切使わない・忘れる」と明示する（`pitfalls.md` 罠4）

## 02. 水彩絵本
```
format: "絵本タッチのカラー漫画（水彩絵本の画風。やわらかい水彩のにじみとあたたかい紙の質感、輪郭線は細く柔らかい茶系、彩度は低〜中のパステル、絵本の挿絵のような光と余白）"
```

```
format: "クレヨン画のカラー漫画（子どもの絵本のようなクレヨン・オイルパステル画。ざらざらした画用紙の目に乗るワックスの粒、塗りムラとかすれ、はみ出す太い手描きの輪郭線、重ね塗りの色の混ざり、白い紙目が透ける粗い塗り。素朴であたたかい手描き感を最優先）"
```

```
format: "パステル画のカラー漫画（ソフトパステル・粉パステル。粉っぽい顔料がざらついた紙の目に乗り、指でぼかしたやわらかい階調、ふんわり淡く光をふくんだ色、輪郭もやわらかくにじむ。白い紙の目が透ける軽やかな塗り。ハイライトは白パステルを重ねて置く。クレヨン／オイルパステルのワックス質のテカリやゴツい太線は使わない）"
```
🎀 **レース・リボン・ガラス瓶・ぬいぐるみ・お菓子など「可愛いもの」の描写が抜群**。クレヨンは素朴であたたかいがゴツいので、可憐さ・繊細さを出したいときはこっち。**やさしいお見舞い・絵本的な話と相性◎**
